# Life Planner · پلنر زندگی

A bilingual (English / فارسی) planner for **habits**, **money** (income, expenses, capital) and **sleep**. One static file, no build step, no server, no tracking. Works on desktop and mobile.

یک پلنر دوزبانه برای **عادت‌ها**، **مالی** (درآمد، مخارج، سرمایه) و **خواب**. فقط یک فایل ثابت، بدون نیاز به سرور.

## Features · امکانات
- Habit grid per month with progress chart, per‑habit analysis, donut and Top 10 · جدول عادت‌ها، نمودار، تحلیل و ۱۰ عادت برتر
- Mood and sleep log · ثبت حال‌وهوا و ساعت خواب
- Income, expenses, capital (savings, gold, stocks…), 6‑month trend · درآمد، هزینه، سرمایه و روند ۶ ماه
- Sleep planner: recommended hours by age, bedtime/wake calculator (90‑minute cycles), daily schedule, water goal · برنامه‌ی خواب
- Jalali and Gregorian calendars · تقویم شمسی و میلادی
- RTL layout, light/dark theme · راست‌به‌چپ، حالت روشن و تیره
- Habit names, ticks and entries are saved in your browser (localStorage). Use **Export backup / Import backup** to move data between devices · نام‌ها و داده‌ها در مرورگر ذخیره می‌شوند؛ برای انتقال از پشتیبان‌گیری استفاده کنید

## Publish on GitHub Pages · انتشار
1. Create a repository and upload `index.html` (and this README).
2. Settings → Pages → Source: *Deploy from a branch* → `main` / root.
3. Open `https://<username>.github.io/<repo>/`.

Fonts load from Google Fonts. Everything else is local.
